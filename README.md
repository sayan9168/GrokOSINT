# 🛡️ GrokOSINT v4.0 — Full Spectrum OSINT

One seed → **everything**: all modules + relationship graph + 2026 framework next-steps.

## Full Spectrum flow
1. Detect email / username / domain / IP
2. Run Email, Holehe, DNS/CT, Wayback, Maigret, IP…
3. Build **graph** (nodes/edges JSON for Gephi/Maltego-style)
4. Print commands for Maigret 1000, Blackbird, Social Analyzer, Subfinder, Amass…

## Install
```bash
git clone https://github.com/sayan9168/GrokOSINT.git && cd GrokOSINT
pip install -r requirements.txt holehe maigret ignorant
python web_app.py
```
